Module 3: Linux

Linux is a free, open-source operating system kernel started by Linus Torvalds in 1991. Combined with GNU tools and other software, it powers servers, phones (Android), supercomputers, and many desktops.

Linux distributions

A distribution (distro) bundles the Linux kernel with a package manager, desktop, and default apps. Select one to learn more.

Open-source software

Open code

Anyone can read, change, and share the source code, usually under licenses such as the GNU GPL.

Free to use

Most distributions and apps cost nothing, which suits schools, startups, and old computers.

Community driven

Thousands of volunteers and companies fix bugs and add features, so security problems are often found and patched quickly.

Common apps

Firefox, LibreOffice, GIMP, VLC, Blender, VS Code, and the Apache and Nginx web servers.

Terminal commands

The terminal lets you control Linux by typing commands. It is fast, scriptable, and works the same over a remote connection.

sudo apt install nameInstall software (Debian/Ubuntu)
man commandOpen the manual for a command

File permissions

Every file has permissions for three groups: the owner, the group, and others. Each group can have read (r = 4), write (w = 2), and execute (x = 1). Add the numbers to get one digit, so read + write = 6. Try the calculator.

Use chmod to change permissions and chown to change the owner. Regular users cannot change system files, which is a big part of Linux security.

Customization

Desktop environments

GNOME, KDE Plasma, Xfce, and Cinnamon each look and work differently. You can switch without changing the rest of the system.

Window managers

Tools like i3 or Sway let advanced users control everything with the keyboard.

Themes and icons

Change colors, fonts, icons, and layouts to suit your taste.

Shells and scripts

Choose bash or zsh and automate tasks with shell scripts.

Server applications

Linux runs most web servers and cloud platforms, and all of the world's top supercomputers. It is stable, secure, and can run for long periods without rebooting.

Advantages and limitations

Advantages

  • Free, open, and highly customizable
  • Strong security and few desktop viruses
  • Runs well on older hardware
  • The standard for servers and development

Limitations

  • Steeper learning curve for beginners
  • Fewer commercial apps, such as Adobe and some games
  • Hardware driver support can vary
  • Many distros to choose from can be confusing
