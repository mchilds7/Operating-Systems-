OS basics: functions and architecture

An operating system (OS) is the software that manages a computer's hardware and lets programs run safely. Learn what it does and how it is built.

The big idea

What is an operating system?

Without an OS, every program would have to control the screen, disk, memory, and network by itself. The OS sits in the middle, shares the hardware fairly between programs, and keeps them from interfering with each other.

Applications

Browsers, games, and editors. They ask the OS for what they need instead of touching hardware directly.

Operating system

The manager. It schedules the CPU, hands out memory, organizes files, runs drivers, and enforces security.

Hardware

The CPU, RAM, storage, display, and network card that actually do the work.

Functions

What the OS does

Process management

Starts, schedules, and stops programs, and shares CPU time so many run at once.

Gives each program its own memory, tracks what is free, and uses disk space as virtual memory when RAM is full.

Protection

User mode, kernel mode, and system calls

User mode

Where normal applications run. They have limited rights, so a crashing app cannot take down the whole system.

Kernel mode

Where the kernel and drivers run with full access to hardware. Only trusted code runs here.

Example: an app opens a file

  1. The app makes a system call (such as open) because it cannot touch the disk directly.
  2. The CPU switches to kernel mode and the kernel takes over.
  3. The kernel checks permissions. If the user is not allowed, the call fails with "permission denied".
  4. A driver reads the disk through the file system code.
  5. The result returns to the app and the CPU goes back to user mode.

Design choices

Types of kernels

TypeHow it worksExamplesTrade-off
MonolithicMost OS services run together inside the kernel.Linux (with loadable modules)Fast, but a bug in a driver can crash the system.
MicrokernelOnly the essentials are in the kernel. Other services run in user mode.QNX, Minix, seL4More isolation, but more message passing.
HybridA mix: a microkernel-style design with many services kept in the kernel for speed.Windows NT, macOS (XNU)Balances speed and structure.

Start-up

How a computer boots

  1. Power on. The processor starts running firmware (UEFI on most PCs, Apple's boot ROM on Macs).
  2. Hardware check. The firmware tests basic hardware and finds the startup disk.
  3. Bootloader. A small program loads the kernel into memory (Windows Boot Manager, GRUB on many Linux systems, iBoot on Macs).
  4. Kernel starts. It sets up memory, loads drivers, and mounts the file system.
  5. System services start. A first process (such as systemd on Linux or launchd on macOS) starts the background services.
  6. Login. The login screen appears and your desktop loads.
