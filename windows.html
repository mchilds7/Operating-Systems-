Module 1: Windows

Windows is Microsoft's operating system and the most widely used desktop OS in the world. First released in 1985, it runs on PCs, laptops, tablets, and servers.

Key features

Graphical interface

The desktop, Start menu, taskbar, and windows let you work with a mouse, keyboard, or touch.

Multitasking

Run many programs at once and switch between them with Alt+Tab or Snap layouts.

Hardware support

Plug-and-play drivers work with a huge range of printers, GPUs, and other devices.

Backward compatibility

Many older programs still run on current versions of Windows.

Built-in tools

Task Manager, Settings, File Explorer, Windows Update, and PowerShell come included.

Gaming

DirectX and wide GPU support make Windows the leading PC gaming platform.

Advantages and disadvantages

Advantages

  • Largest software library, including most games and business apps
  • Works on hardware from many manufacturers at many price points
  • Familiar interface that is easy for beginners
  • Strong support in schools and workplaces

Disadvantages

  • Most targeted OS for malware because of its popularity
  • Can slow down over time without maintenance
  • Updates can restart the PC at inconvenient times
  • Licensed software, so it is not free like most Linux distributions

File management

Windows organizes data in files and folders. Pick a topic below.

File Explorer (open it with Win+E) is the main tool for browsing, copying, moving, renaming, searching, and deleting files. Deleted files go to the Recycle Bin first, so you can restore them.

NTFS is the default Windows file system. It supports large files, file permissions, encryption (EFS), compression, and a journal that helps recover from crashes. FAT32 and exFAT are used on many USB drives.

Storage is split into drive letters such as C:\. A path like C:\Users\Sam\Documents\report.docx shows the drive, folders, and file name. Windows uses backslashes in paths.

  • Ctrl+C / Ctrl+X / Ctrl+V: copy, cut, paste
  • F2: rename
  • Shift+Delete: delete permanently, skipping the Recycle Bin
  • Win+E: open File Explorer

Security

Windows Security

Includes Microsoft Defender Antivirus, a firewall, and ransomware protection.

User Account Control

UAC asks for permission before a program makes system-level changes.

Accounts and permissions

Standard and administrator accounts limit what each user can change. NTFS permissions control access to files.

BitLocker

Encrypts the whole drive so data is unreadable if the device is stolen.

Windows Hello

Sign in with a face, fingerprint, or PIN instead of a password.

Windows Update

Delivers security patches. Keeping it on is one of the best protections.
