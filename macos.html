Module 2: macOS

macOS is Apple's operating system for Mac computers. It is built on a Unix foundation and designed to run only on Apple hardware, which lets Apple tune the software and the machine together.

The macOS interface

Select a part of the desktop to see what it does.

The bar across the top of the screen always shows the menus for the app you are using, plus the clock, Wi-Fi, battery, and Control Center. Unlike Windows, menus live at the top of the screen, not inside each window.

The Dock holds your favorite apps and shows which apps are running. Click an icon to open the app, and drag icons to rearrange them.

Finder is the file manager and the first app that opens when you log in. It shows files in icon, list, column, or gallery view.

Press Cmd+Space to search files, launch apps, do quick math, and look up definitions from one box.

Mission Control shows every open window and your virtual desktops (Spaces) at once, so you can organize work across multiple screens. Open it with a three or four finger swipe up on the trackpad.

Apple hardware integration

Apple silicon

Modern Macs use Apple's own M-series chips. The CPU, GPU, and Neural Engine sit on one chip, which gives strong performance with low power use and long battery life.

Unified memory

The CPU and GPU share one pool of memory, so data does not need to be copied between them.

Secure Enclave and Touch ID

A dedicated security chip stores fingerprint data and encryption keys, and lets you sign in or pay with a touch.

Continuity

Handoff, AirDrop, Universal Clipboard, and Sidecar let a Mac, iPhone, iPad, and Apple Watch work together. You can start an email on one device and finish it on another.

iCloud

Syncs files, photos, passwords, notes, and settings across your Apple devices.

Display and ports

Retina displays, Thunderbolt ports, and a high-quality trackpad are standard across the lineup.

macOS uses the APFS file system, which is optimized for flash storage and supports snapshots and encryption. Time Machine provides automatic backups.

Security

Gatekeeper

Checks that downloaded apps come from identified developers and have been notarized by Apple.

XProtect

Built-in malware detection that Apple updates in the background.

FileVault

Encrypts the entire startup disk so the data is unreadable without your login.

System Integrity Protection

Stops even administrators from changing protected system files.

App sandboxing and permissions

Apps must ask before using your camera, microphone, location, or files in protected folders.

Keychain

Stores passwords and certificates securely and fills them in for you.

Advantages and limitations

Strengths

  • Smooth, consistent experience across hardware and software
  • Strong default security and privacy settings
  • Excellent for creative work and development
  • Long software support and good resale value

Limitations

  • Only runs on Apple hardware, which is expensive
  • Little or no hardware upgradeability, and repairs can be costly
  • Fewer games than Windows
  • Ecosystem lock-in makes switching away harder
  • Older Macs eventually stop receiving new macOS versions
